我们在浏览器里打开的网页，一个网页上有内容部分（文段、图片……）有可交互部分（按钮，链接……），那么它们是怎么被排版到特定的位置？这篇文章的主要内容就是介绍书写网页使用的基本工具，排版网页内容用到的是一种标记语言——**HTML** ，全名“超文本标记语言”(Hypertext Markup Language)。

下面来简单介绍HTML文件应该怎么书写，怎么入门写网页。

# 1.HTML的本质

一个HTML文件的内容都是由一个个**标签（Tag）**组成。你大可把这些标签看成“积木块”，写网页的过程类似于用这些积木搭建你想要的呈现的效果。标签的格式类型主要分为以下两类：

- 成对出现的：`<标签名>内容</标签名> `，比如：`<p>这是一段文字</p>`
- 单个出现的：`<标签名 />`，比如：`<br />`（换行）

用尖括号来标记标签类型，中间写展示的内容，结尾需要加斜杠`/`。

# 2. HTML基本标签类型

要展示的内容不同，所以需要用到不同类型的标签，还有一点是标签名称**不区分大小写**，但是习惯上使用全小写，这里只介绍一些常用的标签：

**内容排版类：**

| 内容类型 | 标签            | 描述                   | 例子                                    |
| -------- | --------------- | ---------------------- | --------------------------------------- |
| 标题     | `<h1>` … `<h6>` | 定义标题大小、级别     | `<h1>一级标题</h1>` `<h2>二级标题</h2>` |
| 文段     | `<p>`           | 定义一个文字段落       | `<p>这是一句文段</p>`                   |
| 换行     | `<br>`          | 插入一个换行符         | `第一行<br>第二行`或是`<br/>`           |
| 分割线   | `<hr>`          | 插入一条水平分割线     | `<hr>`                                  |
| 注释     | `<!-- ... -->`  | 定义HTML代码的注释内容 | `<!-- 这是注释 -->`                     |



**多媒体类：**

| 内容类型 | 标签    | 描述                   | 例子                                                |
| -------- | ------- | :--------------------- | --------------------------------------------------- |
| 超链接   | `<a>`   | 定义超链接，点击可跳转 | `<a href="https://example.com">这是一个链接</a>`    |
| 图片     | `<img>` | 插入图片               | `<img src="图片文件路径或链接", alt="图片描述"/>`   |
| 音频     | `audio` | 插入音频               | `<audio src="音频文件路径或链接" controls></audio>` |
| 视频     | `video` | 插入视频               | `<video src="视频文件路径或链接" controls></video>` |



**文本格式类：**

| 内容类型 | 标签               | 描述             | 例子                               |
| -------- | ------------------ | ---------------- | ---------------------------------- |
| 黑体加粗 | `<strong>` / `<b>` | 给文本加粗       | `<b>这一行加粗</b>`                |
| 斜体     | `<em>` / `<i>`     | 将文本显示为斜体 | `<i>这行是斜体字</i>`              |
| 下划线   | `<ins>` / `<u>`    | 给文本加下划线   | `<u>这行有下划线</u>`              |
| 上下标   | `<sup>` / `<sub>`  | 给文本加上下标   | `H<sub>2</sub>O` / `x<sup>2</sup>` |
| 删除线   | `<del>` / `<s>`    | 给文本划上删除线 | `<del>已删除内容</del>`            |



**框架类标签：**

| 内容类型 | 标签              | 描述                                                 | 例子                      |
| -------- | :---------------- | :--------------------------------------------------- | :------------------------ |
| 声明类型 | `<!DOCTYPE html>` | 声明文档类型为HTML5，必须放在第一行。                | `<!DOCTYPE html>`         |
| 根部分   | `<html>`          | HTML文档的根元素。                                   | `<html> ... </html>`      |
| 头部分   | `<head>`          | 包含文档的元数据（如标题、编码等），不显示在页面中。 | `<head> ... </head>`      |
| 标题部分 | `<title>`         | 定义网页的标题，显示在浏览器标签栏上。               | `<title>我的网页</title>` |
| 元数据   | `<meta>`          | 提供页面的元信息，如字符编码、视口设置等。           | `<meta charset="UTF-8">`  |
| 身体部分 | `<body>`          | 定义文档的主体，所有可见内容都写在这里。             | `<body> ... </body>`      |



**布局类：**

| 内容类型 | 标签     | 描述                                                 | 例子                      |
| -------- | :------- | :--------------------------------------------------- | :------------------------ |
| 块       | `<div>`  | 块级容器，用于对页面进行分区或布局，独占一行。       | `<div> ... </div>`        |
| 行       | `<span>` | 行内容器，用于包裹一小段文本或内联元素，无默认样式。 | `<span>姓名：张三</span>` |



**列表标签：**

| 标签   | 描述                                     | 示例                                  |
| :----- | :--------------------------------------- | :------------------------------------ |
| `<ul>` | 定义**无序列表**，通常以项目符号呈现。   | `<ul><li>项目一</li></ul>`            |
| `<ol>` | 定义**有序列表**，通常以数字序号呈现。   | `<ol><li>第一步</li></ol>`            |
| `<dl>` | 定义**描述列表**，用于展示术语及其描述。 | `<dl><dt>术语</dt><dd>描述</dd></dl>` |
| `<li>` | 定义列表项，用在 `<ul>` 或 `<ol>` 中。   | 见上例                                |



**表格标签：**

| 标签      | 描述                                   | 示例                   |
| :-------- | :------------------------------------- | :--------------------- |
| `<table>` | 定义一个表格。                         | `<table> ... </table>` |
| `<tr>`    | 定义表格中的一行。                     | `<tr> ... </tr>`       |
| `<td>`    | 定义表格中的一个标准单元格。           | `<td>数据</td>`        |
| `<th>`    | 定义表格中的表头单元格，通常加粗居中。 | `<th>表头</th>`        |



# 3. 标签的属性

 标签的属性是写在标签里的配置参数，调整属性可以精确控制标签的行为，也叫做**样式(style)**，样式代码描述了标签的外观





# 4. 网页基本架构

一个网页的HTML文件基本上都是下面这样的格式：

```html
<!DOCTYPE html>    <!-- 声明文档类型，告诉浏览器这是HTML5 -->
<html>              <!-- 网页的根，所有内容都写在里面 -->
    <head>          <!-- 头部：给浏览器看的配置信息（标题、编码） -->
        <meta charset="UTF-8">   <!-- 设置编码为UTF-8，防止乱码 -->
        <title>我的第一个网页</title>  <!-- 浏览器标签栏显示的标题 -->
    </head>
    <body>          <!-- 身体：给用户看的所有内容（文字、图片、按钮） -->
        这里写用户能看到的一切内容！
    </body>
</html>
```
