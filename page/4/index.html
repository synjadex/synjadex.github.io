C语言程序的编译过程

 SynJade 发布于 2026-06-06 收录于 C

从 C 源代码到可执行文件，GCC 工具链会依次经历四个主要阶段：预处理、编译、汇编、链接。每个阶段都可以用 GCC 的特定选项单独观察。

假设源文件为 hello.c：

1. 预处理 (Preprocessing)

  • 任务：处理以 #​ 开头的指令（如 #include​、#define​、#ifdef），展开宏，删除注释，添加行号信息等。
  • 命令：gcc -E hello.c -o hello.i
  • 输出：.i （文本形式，仍是 C 代码，但已经包含所有被包含的头文件和宏展开）。

2. 编译 (Compilation)

  • 任务：将预处理后的 C 代码翻译成汇编语言（与具体 CPU 架构相关）。
  • 命令：gcc -S hello.i -o hello.s​ （也可以从 .c​ 直接：gcc -S hello.c）
  • 输出：.s 汇编文件。

3. 汇编 (Assembly)

  • 任务：将汇编代码转换成机器指令（目标文件，即 .o​ 或 .obj 文件），此时已是二进制格式，但尚未链接库或解析外部符号。
  • 命令：gcc -c hello.s -o hello.o​ （或 gcc -c hello.c）
  • 输出：.o 目标文件（可重定位对象）。

查看内容：objdump -d hello.o 可见二进制指令。

C++中的左值右值与引用

 SynJade 发布于 2026-06-05 收录于 C++

左值(lvalue) 和右值(rvalue)，这两个术语我之前在学C语言时有所耳闻。第一层意思就是字面意思，赋值表达式里等号=左边的叫左值，只能出现在等号右边的叫右值；第二层意思是，可取地址的变量叫左值，不可取地址的变量叫右值。C语言里就这样划分，很简单，平时写代码也不需要彻底弄明白这个。但是但是，在C++里就不一样了，特别是在C++11后（称为现代C++起点），新增了移动语义，引用，生命周期管理这些特性后，C++的值类别就被分得更细了。要写出高性能的C++代码，就得使用引用和移动语义，弄清楚值类别概念是绕不开的，理解值类别概念是掌握移动语义和生命周期管理的前提。这篇文章我就讲解一下C++的值类别，还有如何在使用引用时应用这些概念。
